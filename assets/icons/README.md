# Icon sources

The README uses external, recognizable icon sources only where an official/local SVG is not needed for the core identity:

- [`skillicons.dev`](https://skillicons.dev/) for compact technology icon rows.
- [`shields.io`](https://shields.io/) for text badges with accessible alt labels.
- Google and product logos are requested through those services; no logo files are copied into this repository.

If a future version needs fully offline rendering, download the relevant official brand assets, verify their licenses and place them here. Update the corresponding `<img>` sources in `README.md`; do not add unverified third-party icon packs.
